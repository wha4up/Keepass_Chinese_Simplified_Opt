# KeePass 简体中文语言文件（优化版）

本语言文件基于官方简体中文翻译（由 [LeoDou](https://sourceforge.net/u/leodou/) 维护的 v2.58+ 版本）和 KeePass 官方翻译工具 **TrlUtil 2.61** 的内容进行系统性调整、补充与优化，适用于 **KeePass 2.61 及更高版本**。

## 主要改进

1. **全面审校**  
   修正了原翻译中明显不符合简体中文用语习惯的表述，提升本地化质量。
   示例：
   - `key` → **密钥**（原“密匙”）
   - `group` → **分组**（原“群组”）
   - `hot key` → **快捷键**（原“热键”）

2. **术语统一**  
   对高频词汇、菜单项、对话框按钮等进行了全文件范围的术语一致性检查与修复。  
   示例：
   - `Master Password` → **主密码**（原“管理密码”统一归为 `Master Key`）
   - `Master Key` → **管理密钥**（区别于“主密码”）
   - `String` → **字符串**（原“字串”）

3. **去除口语化**  
   将部分过于口语化、不符合软件界面严谨风格的翻译调整为更专业的书面表达。
   示例：
   - `如果数据库没被修改过，则禁用 “保存” 命令(而不是使其变灰)` → **如果数据库未被修改，则禁用“保存”命令（而非灰显）**
   - `选取了太多的文件。请选择少一些群组，稍后重试。` → **选择的文件过多。请减少选择数量后重试。**
   - `程序策略定义了哪些安全关键操作是允许的，哪些是不允许的。` → **应用策略定义了允许和禁止哪些涉及安全的关键操作。**

4. **修正语义偏差**
   对部分语义存在偏差的翻译进行修正。
   示例：
   - `Compute parameters that lead to a delay of 1 second on this computer.` → **计算参数，使本机运算延迟达到 1 秒。​**（原“参数计算导致在这台电脑上有 1 秒延迟。”）
      > [!tip]
      > 在 KeePass 中，这个“1 秒延迟”是刻意为之的安全设计（Key Derivation Function 的工作因子）。目的是拖慢解锁速度，以此抵御暴力破解。
   - `Up to date` → **已是最新版本**（原“更新”）

5. **格式规范**  
   统一标点符号（如中文句号、逗号、括号等）、快捷键标注（`(&X)`）、空格使用，使界面显示更整洁。

6. **补充缺失条目**  
   针对 KeePass 2.61 新增的功能和设置项，补充了对应的简体中文翻译。

## 使用方法

1. 下载本仓库中的 `Chinese_Simplified.lngx` 文件。
2. 将其放入 KeePass 安装目录下的 `Languages` 文件夹（若没有请自行创建）。
3. 启动 KeePass，依次点击 `View` → `Change Language`，选择 `Chinese (Simplified)`。
4. 按提示重启 KeePass 即可生效。
